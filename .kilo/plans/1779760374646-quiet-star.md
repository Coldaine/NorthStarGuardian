# Plan: Migrate NorthStarGuardian from Anthropic to OpenAI Chat Completions

## Decision

Replace the `anthropic` SDK with `openai` so the codebase uses `client.chat.completions.create()` instead of `client.messages.create()`. This makes OpenAI Chat Completions the canonical interface, which also unlocks Vertex AI Gemini through Google's official OpenAI-compatible endpoint and allows routing through OpenRouter or LiteLLM without additional code changes.

## Test Changes

All existing tests pass mock clients directly via the `client=` parameter. The mock structure mimics the Anthropic SDK response shape, so every mock must be updated to the OpenAI response shape.

### Mock pattern change

| Before (Anthropic) | After (OpenAI) |
|---|---|
| `client.messages.create.return_value` | `client.chat.completions.create.return_value` |
| `client.messages.create.side_effect = [...]` | `client.chat.completions.create.side_effect = [...]` |
| `mock_response.content[0].text = text` | `mock_response.choices[0].message.content = text` |
| `client.messages.create.call_count` | `client.chat.completions.create.call_count` |

### File-by-file changes

**`tests/test_analyze.py`:**
- `_make_client` (line 138): build mock response with `choices[0].message.content = text` instead of `content[0].text = text`
- `_make_all_mock_client` (line 587): same structure change; `messages.create` → `chat.completions.create`
- `_call_llm` patch (line 238): the import path `guardian.analyze._call_llm` remains valid — only the function body changes

**`tests/test_chronicle.py`:**
- `TestAssignSaga._make_client` (line 204): same mock structure change as `test_analyze.py`

**`tests/test_end_to_end.py`:**
- `_llm_response` helper (line 53): return `MagicMock()` with `choices[0].message.content = text` instead of `content[0].text = text`
- `_build_mock_client` (line 62): change `messages.create.side_effect` to `chat.completions.create.side_effect`

**`tests/test_cli.py`:**
- `_make_anthropic_client` patch (lines 390, 448): change patch target to `guardian.cli._make_openai_client`
- `assign_saga` patch (line 409): no change needed (patches the function, not the client)

## Research Backing

- **OpenAI**: Chat Completions remains supported; Responses is recommended for new OpenAI-native projects but is unnecessary here (`platform.openai.com/docs/guides/migrate-to-responses`).
- **Google Vertex AI**: Gemini models are accessible through OpenAI libraries and Chat Completions-style requests via `/endpoints/openapi`. Google recommends the native API only if you are not already using OpenAI libraries (`cloud.google.com/vertex-ai/generative-ai/docs/start/openai`).
- **LiteLLM**: Officially supports Anthropic `/v1/messages` format across OpenAI, Gemini, Vertex AI, and others (`docs.litellm.ai/docs/anthropic_unified/`).
- **OpenRouter**: Exposes `/api/v1/messages` in Anthropic Messages format and documents Anthropic-compatible integrations (`openrouter.ai/docs/api/api-reference/anthropic-messages/create-messages`).
